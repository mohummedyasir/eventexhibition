# Gulf Events Jobs

**The Gulf region's dedicated job board for event & exhibition careers — powered by Business Umbrella.**

A fast, SEO-first, zero-dependency static job board covering event and exhibition
roles across the **UAE, Saudi Arabia, Qatar, Kuwait, Bahrain and Oman**.

## What's inside

- **Static HTML** generated from a single data file — no runtime, no database, no framework.
  Deploy it anywhere (GitHub Pages, Netlify, Vercel, S3, any web host).
- **A page per job** with clean URLs (`/jobs/senior-event-manager-dubai-eve-001/`) and
  Google-ready [`JobPosting`](https://developers.google.com/search/docs/appearance/structured-data/job-posting)
  structured data, so listings are eligible for **Google for Jobs**.
- **Long-tail SEO landing pages** for every category and country
  (`/categories/…`, `/locations/…`) with `ItemList` + `BreadcrumbList` schema.
- **Client-side search & filtering** by keyword, country and category (progressive
  enhancement — every job is still rendered server-side for crawlers and no-JS users).
- **`sitemap.xml`, `robots.txt`, Open Graph / Twitter cards, canonical URLs, web manifest**,
  responsive design, accessible markup and a light performance budget.

## Project structure

```
data/jobs.json          ← the single source of truth for all listings
scripts/build.js        ← static site generator (Node, no dependencies)
scripts/serve.js        ← tiny local preview server
assets/                 ← styles.css, app.js, logo/favicon/OG image
.github/workflows/      ← GitHub Pages deploy workflow

# Generated by the build (committed so the site is deployable as-is):
index.html  jobs/  categories/  locations/  about/  post-a-job/
404.html  sitemap.xml  robots.txt  site.webmanifest
```

## Local development

Requires Node.js 18+.

```bash
npm run build      # regenerate the static site from data/jobs.json
npm run serve      # preview at http://localhost:3000
npm run dev        # build + serve
```

## Adding / editing jobs

Everything is driven by `data/jobs.json`. Add an object to the `jobs` array and run
`npm run build`. Fields:

| Field | Notes |
|---|---|
| `id` | Unique reference, e.g. `eve-013` (also used in the URL slug) |
| `title`, `company`, `companyDescription` | Text |
| `city`, `country`, `countryCode` | `countryCode` is ISO-3166 (`AE`, `SA`, `QA`, `KW`, `BH`, `OM`) |
| `category` | e.g. `Event Management`, `Exhibition & Stands`, `Production & AV` |
| `employmentType` | `FULL_TIME` \| `PART_TIME` \| `CONTRACTOR` \| `TEMPORARY` \| `INTERN` |
| `salaryMin`, `salaryMax`, `currency`, `salaryPeriod` | `salaryPeriod` = `MONTH` \| `YEAR` |
| `datePosted`, `validThrough` | `YYYY-MM-DD` (used in `JobPosting` schema) |
| `featured` | `true` to surface it in the Featured section |
| `summary`, `responsibilities[]`, `requirements[]` | Content |

New categories and locations create their own SEO landing pages automatically.

## SEO

Set your production domain so canonical URLs, Open Graph tags and the sitemap are correct:

```bash
SITE_URL=https://your-domain.com npm run build
```

Then validate:

- **Rich Results Test** — https://search.google.com/test/rich-results (check `JobPosting`)
- **Sitemap** — submit `https://your-domain.com/sitemap.xml` in Google Search Console

## Launch tomorrow

1. **Point the domain / choose a host.** For GitHub Pages: **Settings → Pages → Source:
   GitHub Actions**. The included workflow (`.github/workflows/deploy.yml`) builds and
   deploys on every push to `main`. Set a repo variable `SITE_URL` to your final domain.
   *(Prefer Netlify/Vercel? Just point it at the repo root — no build command needed, the
   HTML is already generated.)*
2. **Set `SITE_URL`** to your real domain and rebuild so canonicals/sitemap are absolute.
3. **Replace the sample jobs** in `data/jobs.json` with live vacancies and rebuild.
4. **Add real contact + application details** (`CONTACT_EMAIL` and the "Post a Job" form
   endpoint are configurable at the top of `scripts/build.js`).
5. **Submit `sitemap.xml`** to Google Search Console and request indexing.
